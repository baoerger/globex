# 跨境选购通则

## 到手价的构成

跨境购物的真实成本是"到手价"，不是商品标价：

    到手价 = 商品小计 + 国际运费 + 关税

三项都受目的国规则影响。Globex 的商品检索工具在传入 ship_to 后会内联返回 landed_price 三分项明细，任何对外报价都应以工具返回为准，不要凭汇率心算。

## 免税额度（de minimis）

多数目的国设有免税额度，小计低于额度时关税为零：

- 美国：约 800 美元档，数码配件常规税率本身也可能为 0
- 欧盟：约 150 欧元档，超出部分按品类税率征收
- 日本：额度较低，且按品类差异大
- 新加坡：约 400 新元档
- 中国：个人物品行邮口径有单次限值，超出按行邮税计征

结论：把单笔金额控制在免税额度内，往往比找更便宜的商品更能压低到手价；多件合并下单可能反而触发关税。

## 运费口径

- 首件全价 + 续件折价是常见计费方式，多件购买的边际运费低于首件。
- 体积重与实重取大值计费，家居、箱包等大体积品类容易被体积重定价。
- 重量敏感品类（户外装备、箱包）在跨境场景的运费占比可达商品价的 20-50%。

## 材质与合规

- 材质敏感（过敏、环保诉求）的买家应优先天然材质：帆布、棉麻、桑蚕丝、竹木、粗陶。
- 锂电池类（移动电源、含电池灯具）受航空与目的国邮寄限制，跨境可达性需单独确认。
- 液体、粉末、动植物制品在多数目的国属限制或禁运品类。
- 电器需确认宽压（100-240V），否则跨境后可能不可用。

## 推荐话术原则

- 数字（价格、库存、运费、关税）一律来自工具返回，不编造、不心算。
- 候选与买家意图不完全一致时，给出最接近的候选并如实说明差异，不要直接回空。
- 不承诺本系统不具备的能力：退款路径、发货时效、物流跟踪都不在能力范围内。
- 买家有预算硬约束时，用检索工具的价格上限参数做结构化过滤，而不是事后人工筛。
